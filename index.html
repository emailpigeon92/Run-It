Everything happens in your browser. Your run file is never uploaded anywhere — there is no server, no account, and no analytics. Close the tab and it's gone.

To colour the card by music, add a songs.csv with columns played_at,artist,track, where played_at is when each track started (07:14:30 or a full timestamp). Connect Spotify to Last.fm and you can pull this automatically from user.getRecentTracks.

Grade adjustment uses the Minetti (2002) cost-of-running curve. It reduces the effect of hills but doesn't remove it — and it can't correct for the fact that you speed up as you warm up.
